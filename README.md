# 👋 Hi, I build for the web
I'm a Front-End Developer focused on building responsive, polished, and maintainable web applications with React, TypeScript, and modern tooling.
I've shipped two full production applications — one frontend-only (17-page SPA with React 18, React Router, Vite) and one full-stack (React 19 + NestJS + PostgreSQL + Socket.IO + Docker). Both live on Vercel, fully responsive, with CI/CD, E2E tests, Storybook component library, and PWA support.

## What I Build With
**Core:** React · TypeScript · JavaScript (ES6+) · HTML5 · CSS3 · SCSS
**Frontend stack:** Vite · React Router · Socket.IO Client · Vitest · Storybook · Playwright
**Backend exposure:** NestJS · Node.js · Prisma ORM · PostgreSQL · REST APIs · JWT · WebSockets
**Tools:** Git · GitHub · npm workspaces · Vercel · Render · Docker · Figma
